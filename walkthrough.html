Walk the full process

The browser-only path (no terminal, no installs)

This walks you through GitHub's own website — the same place the gallery lives. If you can attach a photo to an email, you can do this.

  1. Name your photos first, on your own computer

    Before uploading, rename each file so the order and captions come out right: 01-opening-ceremony.jpg, 02-closing-circle.jpg. Adding a credit in the name? Use 03-photo-by-maria-r.jpg — the gallery will show "Maria R." (first name + last initial, the fellowship's tradition).

  2. Open the album folder on GitHub

    Go to github.com/psychedelicsinrecovery/gallery and click through: assets → albums → convention-2026. A new gathering gets a new folder (step 3 shows how to make one).

  3. Upload your photos

    Click Add file → Upload files, then drag your renamed photos in (or click "choose your files"). Making a new album folder? Choose Add file → Create new file instead, and type the folder name with a trailing slash — like assets/albums/retreat-2027/ — then upload your photos with Upload files from inside it.

  4. Commit the photos

    Scroll down, give the change a friendly title like "Photos from the closing circle", and click Commit changes. That's the whole upload.

  5. Add them to the album list

    Back on the code page, open photos.json, click the pencil icon to edit, and add one line for each photo inside the album's "photos" list:

    { "src": "assets/albums/convention-2026/01-opening-ceremony.jpg",
  "caption": "Opening ceremony" }

    Keep every photo's src exactly matching its filename. Want a credit that doesn't come from the filename? Add "credit": "Maria R.". When you're done, commit that too.

  6. Watch it go live

    In about a minute, open the gallery — your photos are there, captioned and downloadable by the fellowship. If anything looks off, a trusted servant on the Tech Committee can tidy it up; nothing you do here can break anything.

The full walkthrough (terminal)

  1. Gather your photos

    Collect the photos you'd like to share — from your phone, camera, or the shared Drive folder. Pick the keepers: the gallery favors moments over quantity.

  2. Name them with care

    Rename each file with a number prefix so the order is right, and describe the moment: 01-opening-ceremony.jpg, 02-closing-circle.jpg. The filename becomes the caption. Adding a credit? Write photo-by-maria-r in the filename and the gallery shows "Maria R." — first name and last initial, per the fellowship's anonymity tradition.

  3. Place them in an album folder

    Each album is a folder under assets/albums/. For the Denver 2026 gathering, that's assets/albums/convention-2026/. A new gathering gets a new folder — its id, like retreat-2027.

    gallery/
└── assets/
    └── albums/
        └── convention-2026/
            ├── 01-opening-ceremony.jpg
            ├── 02-panel-the-first-decade.jpg
            └── 03-photo-by-maria-r.jpg

  4. Rebuild the manifest

    The gallery page reads one file, photos.json. A tiny zero-dependency script scans your album folders and writes it — captions, credits, and photo dimensions included:

    python3 tools/build_manifest.py

    Optional: an album can carry its own details in assets/albums/<album-id>/_meta.json — a title, the dates, the place, a Pixieset link, even a link to its Astro site.

  5. Commit and push

    Send the photos and the rebuilt manifest to the repository:

    git add .
git commit -m "Add photos to the convention-2026 album"
git push

  6. Watch it go live

    GitHub publishes the gallery in about a minute. Open the gallery and your photos are there — browsable, captioned, and downloadable by the fellowship.

Good to know

  • Anonymity first. Credits use first name + last initial ("Maria R."). If a photo identifies someone who'd rather not appear, it comes down.
  • Consent is the tradition. Every photo is shared with the fellowship's consent. To object to any photo, contact the gallery's trusted servants — removal is immediate and without question.
  • Order matters. The number prefix (01-, 02-…) sets the order photos appear in.
  • No tools at all? The send-it-in path exists exactly for this. Upload to the Drive folder and a trusted servant handles the rest.
  • Big files are fine — Pages serves them quickly worldwide. Very large sets may be resized by the trusted servants to keep the gallery quick.

Photos are shared with the fellowship's consent. If you object to a photo being published, contact the gallery's trusted servants and it will be removed immediately. Photographs belong to the members who made them.
