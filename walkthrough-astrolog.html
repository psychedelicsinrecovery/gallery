Walk the full process

The browser-only path (no terminal, no installs)

This walks you through GitHub's own website — the same place the ledger lives. If you can attach a photo to an email, you can do this.

  1. Name the file first, on your own computer

    The shelf has one naming convention: YYYY-MM-DD-short-name.png — and the date is the day the screenshot captures, not the day you upload it, so the file sorts beside the ledger entry it belongs to. Real examples from the shelf: 2025-10-08-david-lee-ticket-102161.png and 2026-10-14-xdn-panel-main-domain-building.png.

  2. Blur anything personal

    Ticket numbers and support staff names are fine; account numbers, email addresses and members' personal details are not. A quick crop or blur before upload is the whole ritual — the ledger is read by the whole fellowship.

  3. Open the assets folder on GitHub

    Go to github.com/psychedelicsinrecovery/changelog-astro and open the assets folder. A pleasant shortcut: press . (the period key) anywhere on the repo page — GitHub opens github.dev, a code editor right in the browser, where you can simply drag your picture onto the assets folder in the file list.

  4. Upload with the exact name

    On the repo page: Add file → Upload files, drag your picture in, and rename it in the dialog if it isn't named yet. In github.dev: drag the file onto assets/, then check the name one last time.

  5. Commit

    Give the change a friendly title — "Add the XDN panel screenshot" — and commit to main. That's the whole upload. The next sync run publishes it at a permanent address:

    https://psychedelicsinrecovery.github.io/changelog-astro-public/assets/your-file-name.png

  6. Connect it to the ledger

    A picture shines when an entry tells its story. If you edit entries yourself, reference the public URL above from the entry's markdown; if you don't, a trusted servant will wire it in — mention which entry it belongs to when you send word.

The full walkthrough (terminal)

  1. Clone (or update) your copy

    git clone https://github.com/psychedelicsinrecovery/changelog-astro
cd changelog-astro        # or: git pull, if you already have it

  2. Name and place the picture

    Same convention — YYYY-MM-DD-short-name.png, dated by capture — moved into assets/:

    mv ~/Downloads/Screenshot\ 2026-10-14\ at\ 15.21.36.png \
   assets/2026-10-14-xdn-panel-main-domain-building.png

  3. Commit and push

    git add assets/
git commit -m "Add the XDN panel screenshot (2026-10-14)"
git push

    The sync workflow carries assets/ to the public site untouched — the build never reads this folder, so a picture can never break the site.

  4. Reference it from an entry

    <img src="https://psychedelicsinrecovery.github.io/changelog-astro-public/assets/2026-10-14-xdn-panel-main-domain-building.png"
     alt="The WPX XDN panel: the main domain's rebuild spinning"
     style="max-width:100%;border-radius:12px;margin:1rem 0" loading="lazy" />

    Always an alt that says what a person would see — the ledger is read by screen readers too.

Good to know

  • One file, many mentions. Upload once; every entry references the same public URL. There is never a need to duplicate an image.
  • Keep it light. A screenshot is usually well under 1 MB. If yours is huge, a smaller crop helps the ledger load on phones.
  • Stay inside assets/. The repository's checks expect every file in a known place — pictures belong on the shelf, not loose at the repo's root.
  • Nothing here can break the ledger. The build never reads this folder; it simply carries it. Upload, name it well, done.
